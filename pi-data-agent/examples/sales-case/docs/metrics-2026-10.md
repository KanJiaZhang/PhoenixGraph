# 营收口径变更（2026-10-15 生效）

财务与数据平台组共同确认：从 **2026-10-15** 起，对外口径的「营收」改为**净额**（扣退款后），
之前的「营收」保持毛额口径。事实表已经同时具备 `revenue` 与 `net_revenue` 两列，所以这是**口径变更**，
不是数据变更 —— 2026-10-15 之前的报表仍然必须用 `SUM(revenue)` 复现。

## 新口径

指标：营收 = SUM(net_revenue)
单位：元
别名：收入、销售收入、营业额
口径：成交金额扣除退款后的净额；2026-10-15 起生效，此前口径见（2025 版）指标字典。

## 影响

- 看板：2026 年及以后的「营收」数字变小（退款约 2%–4%），历史年份不变。
- 归因：2025 → 2026 的营收变化必须注明口径变更，否则会把口径差当成增长。
- 回溯：用 `asOf` 查 2026-10-01 的模型，必须得到 `SUM(revenue)`。
