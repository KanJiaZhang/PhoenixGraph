# 销售指标口径（2025 版）

本文件是数据团队维护的指标字典，`sales_day` 是事实表（DDL 见 `schema.sql`）。

## 指标

指标：营收 = SUM(revenue)
单位：元
别名：收入、销售收入、营业额
口径：成交金额（毛），未扣除退款。按订单支付时间归属。

指标：净营收 = SUM(net_revenue)
单位：元
别名：净收入
口径：成交金额扣除退款后的净额。

指标：订单数 = SUM(orders)
单位：单
别名：订单量
口径：支付成功的订单数。

指标：客户数 = SUM(customers)
单位：人
别名：买家数
口径：当期下单的去重客户数。

指标：成本 = SUM(cost)
单位：元
口径：投放与履约成本。

指标：客单价 = 营收 / 订单数
单位：元
口径：营收除以订单数；只在营收与订单数都可执行时才有意义。

指标：毛利率 = (营收 - 成本) / 营收
单位：%
口径：毛利润占营收的比例。

## 维度

| 维度 | 字段 | 类型 | 图属性 | 说明 |
|---|---|---|---|---|
| 渠道 | channel | VARCHAR(20) | channel | APP / WEB / MINI / STORE |
| 地区 | region | VARCHAR(20) | region | 华东 / 华南 / 华北 |
| 活动 | campaign | VARCHAR(32) | campaign | 新客季 / 会员日 |
| 日期 | date | DATE | year=year,month=month | 自然年 / 自然月 |

## 术语

| 术语 | 说明 | 别名 |
|---|---|---|
| 退款 | 买家退回并已确认的金额，净营收 = 营收 − 退款 | refund |
| 成交 | 用户完成支付且未退款的订单 | GMV 口径 |

## 主题域

表 `sales_day` 属于 交易 域，负责人是 数据平台组。
